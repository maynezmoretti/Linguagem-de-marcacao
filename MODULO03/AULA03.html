Categorias de Conteúdo HTML5

Elementos de Bloco

Ocupam toda a largura disponível, exemplo: <div>, <p>, <h1>, <section>, <article>

Elementos de Linha

Ocupam apenas o espaço necessário na linha, exemplo: <a>, <span>, <strong>, <em>, <img>

Regras Importantes

Elementos de linha não devem conter elementos de bloco.

Exemplo incorreto:
"Texto"
Exemplo correto:
"Texto"

Categorias de conteúdo:

- Metadata Content

São informações de configuração do arquivo HTML.

<title> // Informa o título da página

<meta> // Definir codificação

<link> e <style> // Importar/anexar CSS

<script> // Importar/anexar comandos JavaScript

- Flow Content

Representa a maior parte dos elementos usados no <body>.

<div> // Cria uma divisão genérica/agrupar "pedaços" de código

<p> // Cria parágrafo dentro da página

<section> // Agrupa conteúdos que partilham do mesmo assunto/ideia

<article> // Conteúdo independente e completo por si só (faz sentido sozinho)

<img> // Importa imagens, desenhos, fotos (não precisa de tag de fechamento)

<form> // Cria formulários (o usuário pode digitar dados e/ou enviar mensagens/fazer login)

- Sectioning Content

Serve para organizar grandes áreas do documento.

<section> // Agrupa conteúdos que partilham do mesmo assunto/ideia

<article> // Conteúdo independente e completo por si só (faz sentido sozinho)

<aside> // Serve para guardar um conteúdo secundário/lateral (links relacionados, anúncios, biografia, etc.)

<nav> // Agrupa links de navegação

- Heading Content

h1, h2, h3, h4, h5 e h6 // Adiciona títulos e subtítulos

<hgroup> // Agrupa elementos de título, exemplo:

"HTML - LIMA
SENAI Americana"

- Phrasing Context

Elementos que marcam textos ou partes de texto.

<span> // Um bloco genérico (não muda nada sozinho), porém pode aplicar CSS ou chamar funções/comportamentos com JavaScript

<a> // Cria um link para direcionar o usuário para outra página, utilizando o atributo href. Exemplo: Clique aqui para acessar o YouTube!

<strong> // Serve para deixar uma parte do texto em negrito

<em> // Serve para deixar uma parte do texto em itálico

<mark> // Serve para adicionar um marcador em uma parte do texto

<img> // Importa imagens, desenhos, fotos (não precisa de tag de fechamento)

- Embedded Content

Utilizado para inserir um conteúdo externo.

<img> // Importa imagens, desenhos, fotos (não precisa de tag de fechamento)

<video> // Adiciona vídeos (pode mostrar botões de play e pause)

<canvas> // Cria uma tela em branco que poderá ser usada pelo JavaScript

<svg> // Desenha gráficos baseados em vetores

<iframe> // Coloca outra página inteira dentro do seu website (muito utilizado para adicionar mapas e vídeos)

- Interactive Content

Permite interações com o usuário.

<a> // Cria um link para direcionar o usuário para outra página, utilizando o atributo href

<button> // Cria botões. Exemplo:

<input> // Usado para receber dados do usuário. Dentre os dados aceitos estão:

- type="text": Campo de texto curto

- type="password": Oculta os caracteres digitados

- type="email" ou "number": Valida os dados específicos

- type="checkbox" ou "radio": Caixas de marcação e escolha única

***type é uma tag que não precisa de fechamento

<select> // Cria uma caixa de seleção em formato de linha suspensa (dropdown)

<textarea> // Cria uma caixa com várias linhas (serve para textos longos, comentários, mensagens e biografias)

Listas em HTML

- Lista não ordenada (ul). Exemplo:

  • Item 1
  • Item 2
  • Item 3
  • Item 4

- Lista ordenada (ol). Exemplo:

  1. Item 1
  2. Item 2
  3. Item 3
  4. Item 4
